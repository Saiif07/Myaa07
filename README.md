# MYRAA
APK: push this folder (myraa.py at repo root) to GitHub -> Actions -> "Build APK" -> download `myraa-debug-apk`.
Standalone: Settings -> Model (provider:model) + API key. Full agents: Backend URL + token (python3 myraa.py serve).
Wake: tap WAKE ON, allow mic + notifications, say "Hey Myraa". Tap BATTERY and allow unrestricted battery so Android doesn't kill it.
If the app ever crashes, the next launch prints the crash note on screen - send it to Claude to fix.
